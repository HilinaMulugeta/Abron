# Dependencies to Install

Run these commands to install the required dependencies:

```bash
npm install recharts react-loading-skeleton react-intersection-observer axios
```

If you encounter SSL certificate issues, try:
```bash
npm config set strict-ssl false
# or
npm install --registry https://registry.npmjs.org/
```

## Required Dependencies:
- **recharts**: For charts and graphs in admin dashboard
- **react-loading-skeleton**: For skeleton loading components
- **react-intersection-observer**: For lazy loading and infinite scroll
- **axios**: For API calls and data fetching

## Optional Dependencies (for advanced features):
- **react-hook-form**: For better form handling
- **@headlessui/react**: For accessible UI components
- **clsx**: For conditional CSS classes
